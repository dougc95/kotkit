## Read these alongside the images

The recall/self-scoring panels represent sequential steps. Recovery panels illustrate alternative situations. The image boards include example text and occasional raster-generation imperfections; do not reproduce typographical errors or design annotations in the product.

The completed-results example uses baseline switch counts 6/4 and final counts 3/3: means 5 and 3, two fewer switches, 40% reduction. Recall is held at 4/5 for illustration. These are not Douglas's measurements.

These boards cover eight core screen concepts plus three alternate-state concepts. Read the PRD for the additional mixed, incomplete, zero-baseline and increased-switch result variants; do not infer that only the pictured happy path is required.
